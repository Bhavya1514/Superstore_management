# Superstore_management

The “Superstore Management System” is based on the sales transaction of items in supermarket. The first activity is based on adding the store details and the details of the distributor. This authority is given only to admin. He also has the right to delete any item. The store owner has the right to add the names of the items which are in the supermarket and also the quantity left in the store. The distributor takes the orders and updates the order details. This is not a huge task. The system will also display the the items and the quantities of each item. Finally, each of the details will be displayed for each store present. This will be saved in the database. Any periodic records can be viewed at any time. Admin provides a unique username and password for each store owner and each distributor through which he can login. By using this method its easy to track the details of the store and the orders by each store. This is an efficient way of managing a superstore.  


Installation and Running:
1. Download Xampp(phpMyAdmin). 
2. Create a folder of all the front and backend codes. Copy this folder to htdocs on xampp. 
3. Open the xampp control panel, run apache and MySQL.
 4. Also click on admin for both. 
5. In phpMyadmin, create a new database and chose the backend code. This creates all the tables 
6. In the apache admin, type the folder name with front and backend codes in the web address instead of dashboard. This helps access the webpage.
